## Project Overview

**data-anlysis-ceia** is a Python data analysis project using modern tooling:
- **Language**: Python 3.12+
- **Package Manager**: `uv` (fast, modern Python package manager)
- **Primary Dependency**: pandas (for data manipulation and analysis)
- **Project Type**: Data analysis utility (entry point: `main.py`)

## Development Setup

### Prerequisites
- Python 3.12 or later
- `uv` package manager installed globally

### Installation
```bash
uv sync
```
This installs dependencies and sets up the virtual environment.

### Running the Project
```bash
uv run python main.py
```

Or directly with Python:
```bash
source .venv/bin/activate
python main.py
```

## Package Management with `uv`

- **Add dependencies**: `uv add <package-name>`
- **Add dev dependencies**: `uv add --dev <package-name>`
- **Sync dependencies**: `uv sync` (applies lockfile changes)
- **Update lockfile**: `uv sync --refresh` (re-resolve all dependencies)

All dependency changes are committed to `uv.lock` to ensure reproducible builds across environments.

## Key Files
- `pyproject.toml` — Project metadata and dependency definitions
- `uv.lock` — Lockfile (do not edit manually; generated by `uv`)
- `.python-version` — Python version specification for `uv`
- `main.py` — Primary entry point
